### What I work on

Nine years building backend systems, currently on the Java/Spring Boot services behind card
switching, core banking integration and financial batch processing at a retail bank.

Most of my work sits on money-movement paths, which shapes how I build: idempotent operations,
explicit retry and compensation semantics, reconciliation between systems that disagree, audit
trails, and approval controls. Correctness over velocity.

I like the diagnostic end of the job — the defects that survive years in production because
monitoring never surfaces them.
